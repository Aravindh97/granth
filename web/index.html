granth · search with citations, for agents

Documents are parsed by layout, chunked under their headings and indexed for keyword (BM25) and vector search, fused with reciprocal rank fusion. Every result says exactly where it came from. The parser, chunker, index and search from the repo run here as Go WebAssembly.
